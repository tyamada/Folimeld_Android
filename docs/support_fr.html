Assistance & FAQ

Q : Mes données PDF sont-elles sécurisées ?

Oui. Folimeld est construit avec une philosophie « Local First ». Vos fichiers PDF ne sont jamais téléchargés sur des serveurs Internet. Tout le traitement se passe entièrement sur votre appareil Android.

Q : J'ai fait une erreur. Puis-je annuler ?

Oui. Vous pouvez annuler jusqu'à 20 actions récentes en utilisant le bouton « Annuler » sur la barre d'outils ou le raccourci clavier Ctrl + Z.

Q : Est-ce que cela fonctionne bien sur les Chromebooks ?

Oui. Folimeld dispose d'une mise en page en grille réactive qui optimise le placement des miniatures pour n'importe quelle taille d'écran. Il prend également en charge les raccourcis clavier standard pour une expérience de type bureau.

Q : J'ai trouvé un bug. Où puis-je le signaler ?

Les rapports de bogues et les suggestions de fonctionnalités sont les bienvenus sur notre page GitHub Issues.
