Support & FAQ

F: Sind meine PDF-Daten sicher?

Ja. Folimeld basiert auf einer „Local-First“-Philosophie. Ihre PDF-Dateien werden niemals auf Internet-Server hochgeladen. Die gesamte Verarbeitung findet ausschließlich auf Ihrem Android-Gerät statt.

F: Ich habe einen Fehler gemacht. Kann ich das rückgängig machen?

Ja. Sie können bis zu 20 letzte Aktionen über die Schaltfläche „Rückgängig“ in der Symbolleiste oder das Tastaturkürzel Strg + Z rückgängig machen.

F: Funktioniert es gut auf Chromebooks?

Ja. Folimeld verfügt über ein responsives Grid-Layout, das die Platzierung der Vorschaubilder für jede Bildschirmgröße optimiert. Es unterstützt auch Standard-Tastaturkürzel für ein desktop-ähnliches Erlebnis.

F: Ich habe einen Fehler gefunden. Wo kann ich ihn melden?

Fehlerberichte und Funktionsvorschläge sind auf unserer GitHub Issues-Seite willkommen.
