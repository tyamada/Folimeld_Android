Folimeld for Android

可视化地重新排列、旋转、插入和删除 PDF 页面。

从 GitHub 下载

主要特性

🎨 直观的可视化编辑

通过缩略图预览，以类似于拖放的直观方式自由更改页面布局。

🔄 批量处理多页

可以同时选择多页进行移动、旋转或删除。完全支持撤销 (Undo) 和重做 (Redo)。

🔒 隐私优先

所有处理均在设备本地完成。您的 PDF 文件永远不会被上传到任何外部服务器。

💻 针对平板电脑和 Chromebook 优化

支持大屏幕设备和物理键盘，包括 Ctrl+S（保存）和 Ctrl+Z（撤销）等标准快捷键。
