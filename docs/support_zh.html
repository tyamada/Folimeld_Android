支持与常见问题 (FAQ)

Q: 我的 PDF 数据安全吗？

是的。Folimeld 基于“本地优先”的设计理念。您的 PDF 文件绝不会被上传到互联网服务器，所有的编辑操作都仅在您的 Android 设备上完成。

Q: 我在编辑时出错了。可以撤销吗？

是的。您可以使用工具栏上的“撤销 (Undo)”按钮，或使用键盘快捷键 Ctrl + Z，最多可撤销最近的 20 步操作。

Q: 它在 Chromebook 或平板电脑上运行良好吗？

是的。Folimeld 采用了响应式网格布局，可根据屏幕大小自动优化缩略图的排列。同时它也完全支持外接键盘快捷键，提供类似桌面端的体验。

Q: 我发现了一个 Bug。应该在哪里报告？

我们非常欢迎在 GitHub Issues 页面提交 Bug 报告或功能建议。
