Folimeld for Android

Visually rearrange, rotate, insert, and delete PDF pages.

Download from GitHub

Key Features

🎨 Visual Editing

Rearrange PDF pages using thumbnail previews with intuitive operations.

🔄 Batch Operations

Select multiple pages and move, rotate, or delete them all at once. Full Undo/Redo support.

🔒 Privacy First

All processing is done locally on your device. Your PDF files are never uploaded to any server.

💻 Optimized for Tablets & Chrome OS

Full support for large screens and physical keyboards, including standard shortcuts like Ctrl+S and Ctrl+Z.
