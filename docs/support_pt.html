Suporte e Perguntas Frequentes (FAQ)

P: Os meus dados em PDF estão seguros?

Sim. O Folimeld foi construído com uma filosofia "Local First". Os seus ficheiros PDF nunca são carregados para servidores da Internet. Todo o processamento ocorre inteiramente no seu dispositivo Android.

P: Cometi um erro. Posso desfazer?

Sim. Pode desfazer até as últimas 20 ações utilizando o botão "Desfazer" na barra de ferramentas ou o atalho de teclado Ctrl + Z.

P: Funciona bem em Chromebooks?

Sim. O Folimeld apresenta um layout de grelha responsivo que otimiza a colocação das miniaturas para qualquer tamanho de ecrã. Também suporta atalhos de teclado padrão para uma experiência semelhante à de um desktop.

P: Encontrei um erro. Onde posso reportá-lo?

Relatórios de erros e sugestões de funcionalidades são bem-vindos na nossa página de GitHub Issues.
