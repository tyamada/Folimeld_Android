Folimeld für Android

PDF-Seiten visuell neu anordnen, drehen, einfügen und löschen.

Von GitHub herunterladen

Hauptmerkmale

🎨 Visuelle Bearbeitung

Ordnen Sie PDF-Seiten mithilfe von Vorschaubildern mit intuitiven Drag-and-Drop-ähnlichen Operationen neu an.

🔄 Stapelverarbeitung

Wählen Sie mehrere Seiten aus und verschieben, drehen oder löschen Sie diese gleichzeitig. Volle Unterstützung für Rückgängig/Wiederholen (Undo/Redo).

🔒 Datenschutz an erster Stelle

Die gesamte Verarbeitung erfolgt lokal auf Ihrem Gerät. Ihre PDF-Dateien werden niemals auf einen Server hochgeladen.

💻 Optimiert für Tablets & Chromebooks

Vollständige Unterstützung für große Bildschirme und physische Tastaturen, einschließlich Standardkürzeln wie Strg+S und Strg+Z.
