Folimeld para Android

Reorganice, rote, inserte y elimine páginas PDF visualmente.

Descargar desde GitHub

Características principales

🎨 Edición visual

Reorganice las páginas PDF mediante vistas previas de miniaturas con operaciones intuitivas de arrastrar y soltar.

🔄 Operaciones por lotes

Seleccione varias páginas y muévalas, rótelas o elimínelas todas a la vez. Soporte completo para Deshacer/Rehacer (Undo/Redo).

🔒 La privacidad es lo primero

Todo el procesamiento se realiza localmente en su dispositivo. Sus archivos PDF nunca se suben a ningún servidor externo.

💻 Optimizado para tabletas y Chromebooks

Soporte completo para pantallas grandes y teclados físicos, incluidos los atajos estándar como Ctrl+S y Ctrl+Z.
