Folimeld para Android

Reorganize, gire, insira e exclua páginas de PDF visualmente.

Baixar do GitHub

Principais Características

🎨 Edição Visual

Reorganize as páginas do PDF usando visualizações de miniaturas com operações intuitivas, semelhantes a arrastar e soltar.

🔄 Operações em Lote

Selecione várias páginas e mova, gire ou exclua todas de uma vez. Suporte completo para Desfazer/Refazer (Undo/Redo).

🔒 Privacidade em Primeiro Lugar

Todo o processamento é feito localmente no seu dispositivo. Seus arquivos PDF nunca são enviados para nenhum servidor externo.

💻 Otimizado para Tablets e Chromebooks

Suporte completo para telas grandes e teclados físicos, incluindo atalhos padrão como Ctrl+S e Ctrl+Z.
