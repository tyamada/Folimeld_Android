Folimeld for Android

PDFのページ並べ替え、回転、挿入、削除を視覚的に。

最新版をダウンロード (GitHub)

主な特長

🎨 直感的なビジュアル編集

サムネイルを見ながら、ドラッグ操作に近い感覚でページ構成を自由に変更できます。

🔄 複数ページの一括操作

移動、回転、削除を複数のページに対して一度に実行できます。Undo/Redo（元に戻す・やり直し）にも対応。

🔒 プライバシー重視

すべての処理は端末内で行われます。ファイルを外部サーバーに送信することはありません。

💻 デスクトップ・Chromebook最適化

大画面デバイスや物理キーボードに対応。Ctrl+S（保存）やCtrl+Z（Undo）などのショートカットが使えます。
