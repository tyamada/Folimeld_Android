Support & FAQ

Q: Is my PDF data secure?

Yes. Folimeld is built with a "Local First" philosophy. Your PDF files are never uploaded to any Internet servers. All processing happens entirely on your Android device.

Q: I made a mistake. Can I undo?

Yes. You can undo up to 20 recent actions using the "Undo" button on the toolbar or the Ctrl + Z keyboard shortcut.

Q: Does it work well on Chromebooks?

Yes. Folimeld features a responsive grid layout that optimizes thumbnail placement for any screen size. It also supports standard keyboard shortcuts for a desktop-like experience.

Q: I found a bug. Where can I report it?

Bug reports and feature suggestions are welcome on our GitHub Issues page.
