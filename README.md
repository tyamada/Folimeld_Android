# Folimeld for Android

[English](README_en.md) | 日本語 

Folimeld は、PDF のページを見ながら並べ替え、回転、挿入、削除できる Android アプリです。デスクトップ版の機能を Android のモバイル・タブレット環境や Chrome OS 向けに最適化して移植しました。編集するファイルを外部サービスへ送信せず、ローカル環境で処理します。

## 特長

- **ビジュアル編集**: サムネイルを見ながらPDFページを並べ替え。
- **一括操作**: 複数ページをまとめて選択・移動・回転・削除。
- **ページ挿入**: 別のPDFや、同じサイズの空白ページを挿入。
- **詳細設定**: PDFバージョン、ページレイアウト、綴じ方向を編集。
- **セキュリティ**: 閲覧パスワードの設定と解除に対応。
- **デバイス最適化**: スマートフォン、タブレット、および Chromebook（キーボードショートカット対応）で動作。
- **プライバシー**: すべての処理は端末内で行われます。

## 使い方

1. アプリを起動し、右上の「開く」アイコンからPDFを選択します。
2. ページをタップして選択します（複数選択可）。
3. 下部のツールバーを使用して、移動、回転、挿入、削除を行います。
4. 右上の「保存」アイコンでPDFを書き出します。

### キーボードショートカット (Chromebook / 外付けキーボード)

- `Ctrl + O`: 開く
- `Ctrl + S`: 保存
- `Delete` / `Backspace`: 削除
- `Ctrl + I`: PDFを挿入
- `Ctrl + Shift + I`: 空白ページを挿入
- `Alt + Up/Down`: ページを前後へ移動
- `Ctrl + Left/Right`: ページを左右に回転

## 開発環境

- **言語**: Kotlin
- **UI**: Jetpack Compose (Material 3)
- **DI**: Hilt
- **PDFエンジン**: PdfBox-Android
